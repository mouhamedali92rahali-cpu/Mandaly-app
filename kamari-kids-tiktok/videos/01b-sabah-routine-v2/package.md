# 01b — روتين الصباح، النسخة 2 (تجربة النسق الجديد + الهوية الصوتية)

نفس محتوى ورسالة الفيديو 01 (انظر `../01-sabah-routine/package.md` للغرض والأصول والوصف)، مع تطبيق أفكار فيديو النسق المرجعي وإضافة هوية صوتية.

**الملفات:** `out/01b-sabah-routine-v2.mp4` (مؤثرات + موسيقى خلفية خفيفة) · `out/01b-sabah-routine-v2-sfx-only.mp4` (نفس الصورة، مؤثرات فقط) · `vo.srt`

## ما تغيّر بصريًا
| الفكرة | أين تظهر |
|---|---|
| **ليل ← نهار ← ليل:** الكحلي للمشكلة (صباح فوضوي)، الكريمي للحل، والكحلي مع القمر للنهاية | دائرة «شروق» تتسع من المنبه (3.3ث)، ودائرة «قمر» في النهاية (17ث) |
| **الكتابة كلمة كلمة** بإيقاع القراءة | كل العناوين |
| **شريط العبارة المفتاحية** بلون معاكس | «نعاودو نفس الكلام؟»، «بالصّور»، «ونعملوها معاه»، «هو ينقل الكرت» (أصفر)، «يشارك في روتينو» |
| **علامة صغيرة ثابتة** «قمري كيدز» + هلال أعلى الوسط | طوال الفيديو؛ لونها يتبدل مع الخلفية |
| **نهاية أقصر** (~2.3ث) | القمر + الاسم + «تابعنا باش تشوف التجربة» |
| **حركة الفعل:** قطرات ماء تتطاير مع «نغسل وجهي» | 7.1–8.4ث |

## خريطة الصوت (الثانية → الصوت → لماذا)
| الزمن | الصوت | الوظيفة |
|---|---|---|
| 0–1ث | تك-توك + منبه بجرس ناعم (ليس رنينًا حادًا) | يعرّف «الصباح» دون إزعاج الطفل أو الولي |
| مع كل كلمة | نقرة ماريمبا خشبية خافتة، تصعد درجة مع كل كلمة | تشدّ الانتباه للكتابة، وتعطي إحساس «لعب» |
| 0.75 / 1.15 / 1.55ث | «بوب» صغير صاعد لكل فقاعة (قوم! البس! فطّر!) | فكاهة خفيفة بدل التوتر |
| 3.3ث | نفَس هوائي + هارب صاعد (شروق) | الانتقال من المشكلة إلى الحل |
| من 3.4 إلى 17.4ث | موسيقى أوكوليلي أصلية هادئة (دو-صول-لا-فا، 88 نبضة) | دفء العائلة؛ تنخفض تلقائيًا تحت التعليق الصوتي عند إضافته |
| 6.7 / 10.15ث | نغمة «انتباه» واحدة | «شوف هذا الكرت» |
| 7.2ث | قطرات ماء صغيرة | صوت الفعل نفسه (غسل الوجه) |
| 10.65ث | حفيف قماش | صوت الفعل نفسه (اللبس) |
| 8.4 / 11.6ث | رفع + انزلاق ورق | حركة الكرت مفهومة بالسمع |
| 9.25 / 12.45ث | نقرة استقرار + نغمتان صاعدتان على الكاليمبا | لحظة «عملت!» — احتفاء هادئ، لا تصفيق ولا صراخ |
| 14.2ث | لمعة نجوم | وقفة الفخر الصغيرة |
| 17.65ث | **التوقيع الصوتي لقمري كيدز:** صول-دو-مي صاعدة | يتكرر في نهاية كل فيديو لتُعرف القناة بالسمع |

**مبادئ الصوت:** كل النغمات من سلّم خماسي واحد (لا نشاز أبدًا)، لا أصوات «خطأ»، لا ضحك أو تصفيق مسجّل، ولا موسيقى بحقوق. الجهارة النهائية مطبّعة إلى ~-16 LUFS (القمة -1.4 dBFS) حتى لا يكون الفيديو أخفت من غيره في التصفح. كل الأصوات مولّدة بالكود في `engine/sound.mjs`.

## ما يحتاج أذنك
لم أستطع الاستماع للنتيجة بنفسي. فحصتُ المستويات والطيف الترددي فقط، وأصلحت به تشويشًا حادًا في أصوات الورق والهواء. **راجع على الهاتف:**
- [ ] هل الموسيقى الخلفية مناسبة أم تفضّل نسخة «مؤثرات فقط»؟
- [ ] هل نقرات الكلمات لطيفة أم كثيرة؟ (يمكن الإبقاء عليها للعناوين فقط أو حذفها)
- [ ] هل التوقيع الصوتي في النهاية مميز بما يكفي؟
